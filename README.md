# AI Website Builder

A full-stack AI-powered website generator!

## Features

- Authentication (Login / Signup)
- Protected Routes using JWT
- AI Website Content Generation
- Create, Read, Update, Delete Websites
- Pagination
- Form Validation
- Loading & Error States
- Responsive UI

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- React Router DOM
- Axios
- React Hook Form
- Context API

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT Authentication
- OpenAI API
- Zod Validation

## Live Demo

Live on: https://web-builder-three-kohl.vercel.app

## Setup

Frontend

cd frontend  
npm install  
npm run dev

Backend

cd backend  
npm install  
npm run dev

## Environment Variables

Frontend

VITE_API_URL=your_backend_url/api/v1

Backend

DATABASE_URL=your_database_url  
JWT_SECRET=your_secret  
OPENAI_API_KEY=your_api_key
